# Rigorous Dev Local Settings (Example)

This is an example configuration file for the Rigorous Dev plugin.

## How to Use

1. Copy this file to `.claude/rigorous-dev.local.md` in your project
2. Customize the YAML frontmatter settings above
3. Add project-specific notes in the markdown section below

**Note:** The `.claude/rigorous-dev.local.md` file is gitignored by default, so your local preferences won't be committed.

## Configuration Options

### artifacts_directory

**Type:** string
**Default:** `.claude/rigorous-dev-artifacts`

Where to store workflow artifacts (requirements, architecture specs, etc.)

**Examples:**
- `.claude/rigorous-dev-artifacts` - Hidden in .claude (gitignored)
- `./docs/sdlc` - Version controlled with your docs
- `./artifacts` - Separate artifacts directory

**Tip:** If you want to version control your artifacts, use a path outside `.claude/`

### max_iterations

**Type:** number
**Default:** 3

Maximum producer-critic iterations before escalating to user for guidance.

**Range:** 1-10 (3 recommended)

### auto_save

**Type:** boolean
**Default:** true

Whether to automatically save workflow state after each phase transition.

**Options:**
- `true` - Auto-save (recommended)
- `false` - Manual save via `/rigorous-dev:status`

### default_project_name

**Type:** string
**Default:** Current directory name

Default project name to use when starting a new workflow.

**Example:** `"My Awesome Project"`
